# 弹层与通知行为

共享对话框采用通过 Portal 挂载到 body 的 Radix Dialog，保留无障碍标题、
可选说明、初始与返回焦点，以及工作流需要时的禁止关闭状态。居中的遮罩保留
2px 背景模糊。Radix Select 的 Portal 选项可以在对话框上方正常使用；
不使用会以浏览器顶层遮挡选项的原生 `showModal()`。

在统一应用布局内、可滚动路由内容之外，只挂载一次 `NotificationToaster`。
它通过 body Portal 使用 Sonner 的视口固定右上角通知栈，位于对话框和下拉框
上方，并提供可交互的关闭按钮。

异步反馈刻意不跟随按钮。全局“最后点击”推测不能识别延迟结果的来源，
并会让无关点击或滚动改变反馈位置。统一视口位置以靠近触发操作的便利性换取
可见性与位置可预测性。成功确认显示一秒，错误与警告显示十秒，信息显示五秒；
调用方可针对特殊情况覆盖时长。术语添加与编辑失败还会保留在当前表单内，
直到重试或开始新的编辑会话，确保通知消失后仍可查看错误并修正输入。

Web/Desktop 的定向模拟测试覆盖术语选项选择、表单内保存错误、对话框上方
可读通知，以及内容滚动和无关点击后的慢请求反馈。不调用模型或外部服务。
