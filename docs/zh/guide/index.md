# 文译入门

文译通过你选择的模型服务翻译书籍与长篇文字。先选择适合自己的运行方式；
各端独立保存项目状态，不共用一个实时项目数据库。

## 选择运行方式

| 方式 | 从这里开始 | 适合的场景 |
| --- | --- | --- |
| Desktop | [安装与设置](desktop.md) | 本地项目、原生文件选择与集成校阅工作台 |
| Web | [部署浏览器工作台](web.md) | 使用 PostgreSQL 和 Redis 的自托管服务 |
| CLI | [安装与翻译](cli.md) | 无需服务端的终端操作与自动化 |

Desktop 安装包自带翻译引擎和 Python 运行环境。使用发行版不需要搭建源码开发环境。

## 翻译与校阅一本书

Desktop 与 Web 共用[工作台指南](workspace.md)：从导入文件、选择模型，
到翻译、校阅、术语、Review 和导出。各平台的安装、凭据和备份方式分别保留在
Desktop 与 Web 指南中。

[翻译流程](pipeline.md)解释准备、上下文、三稿精翻、Review 与断点续跑。
这些选择同时影响质量和费用；模型输出仍需人工检查。

## 查配置与格式

- [配置参考](../reference/configuration.md)：提供商、模型路由、流程选项和默认值。
- [格式参考](../reference/formats.md)：输入输出支持、PDF 后端、版式限制与双语导出。

除非使用本地模型，翻译会将书籍文本发送给所配置的模型提供商；PDF 解析也可能使用
外部服务。发送前请确认服务的隐私条款，以及自己对文本拥有的使用权限。

需要修改或打包文译？请进入独立的[开发维护文档](../development/index.md)。
