# Web 与 Desktop 工作台

Web 与 Desktop 共用以下流程，但项目和配置彼此独立。工作台面向电脑，不支持手机／平板浏览器。翻译各阶段的说明见[翻译流程](pipeline.md)。

## 创建项目

1. 选择**创建项目**，填写书名和源／目标语言。源语言可自动检测；项目名称为空时，选择文件会建议使用文件名。
2. 拖入一个非空 EPUB、DOCX、FB2、TXT、Markdown、HTML 或 PDF，或选择**浏览文件**。PDF 需在上传前选择解析器：默认 MinerU，BabelDOC 是可选的保留版式路径。参见[格式支持](../reference/formats.md)与 [Desktop 的 BabelDOC 插件](desktop.md#可选-babeldoc-插件)。
3. 选择**翻译风格**：默认**文学**；**学术**侧重论证、概念区分、限定条件与引文。它应用于译前准备、翻译、术语、润色和 Review。
4. 决定是否开启**三译合润**和**创建后执行译前准备**，两个开关默认均关闭。
5. 点击**创建项目**。Desktop 还可选择[项目文件夹](desktop.md#数据位置与备份)。

关闭**三译合润**时使用标准翻译；打开后，文译以同一份原文和上下文生成**三份独立草稿，再综合三稿进行一次合成**，不是三选一。此模式启用必需的润色步骤，会增加模型用量，不提供独立的初稿并发数选项。翻译方式和风格随项目保存，之后不能更改。

**创建后执行译前准备**决定是否在创建后立即准备；关闭只是推迟到启动流程时执行 AI 准备，不是禁用准备步骤。准备生成文风指导，并按配置进行全书预理解，**不抽取或预填术语，也不预填人物译名**。术语来自翻译过程中已完成的原译文对，或手动添加／导入；重复准备保留已有词条。

创建后进入项目总览，解析或准备继续在后台执行。解析完成即可**查看目录与原文**，无需等待 AI 准备完成，模型调用失败也不妨碍阅读已解析原文。解析不需要翻译模型凭据，但 PDF 转换仍需要所选解析服务；初始化完成前，标题与译文保持只读。

上传开始后关闭创建对话框不会取消请求，项目可能仍在后台创建。Desktop 原生上传失败后，重试前需重新选择原文。初始化后若更换原文或目标语言，应新建项目。

## 选择模型与流程

全局**设置 → 模型与接口**管理提供商连接与注册模型，**默认模型**选择**高质量**、**经济**、**快速**三个档位。**项目配置**为这三个档位选择已注册模型、调整本项目流程，不负责添加新提供商或注册模型。

1. 配置连接并登记所需模型名称。Desktop 使用[凭据控件](desktop.md#api-密钥)填写密钥；Web 从服务端环境变量读取，表单只保存变量名，不保存秘密值。缺少密钥时请联系部署管理员。
2. 使用**模型名称**旁的刷新控件获取名称，或直接输入。获取会访问提供商的模型列表服务，但**不消耗模型 token**；使用当前编辑中的连接，包括未保存的接口地址，Desktop 也可使用刚输入的密钥。Web 使用新的环境变量名获取列表前需先保存。
3. **保存配置**后再**测试连接**。测试会向每个已保存模型发送一次简短的真实请求，显示连通性、延迟及失败原因，**消耗 token，并可能产生费用**。配置校验和凭据可用性检查不发送模型请求。
4. 开始前检查所选档位与流程开关。普通控件提供全书预理解、润色、全书审校及审校后自动修复。

按步骤指定模型与回退、Token 预算、并发、注释对齐和解析后端默认值通过**高级 YAML 配置**调整。**项目配置**在翻译流程下方直接展示编辑器，全局设置则通过**高级**分类进入。创建项目时也可选择 PDF 解析后端。

修改 YAML 后，先校验或保存，再继续使用普通控件；未校验的 YAML 会使这些控件暂时禁用。普通控件的修改会保留草稿中已有的高级配置。**校验配置**检查当前草稿，不发送模型请求。

内置流程默认开启全书预理解、润色、Review 和 Review Autofix，已有项目的覆盖配置仍优先。尤其要注意，Review **默认不是只读操作**；运行前请阅读[全书 Review](#全书-review)。

新建和恢复的任务使用已保存设置，运行中任务保留已取得的配置。修改项目配置前须先暂停。全局设置中切换分类会保留草稿，但离开设置或刷新会丢弃未保存修改；恢复默认先生成草稿，保存后才生效。完整选项见[配置参考](../reference/configuration.md)。

## 翻译、暂停与续跑

在项目总览开始翻译。**当前翻译流程**显示实际任务类型、状态和最后上报的阶段；保存的段落数、章节、用量和运行时间随进度更新。模型用量在提供商返回统计后显示；未知计数为 `—`，不是零，token 计数也不等于账单金额。

对当前排队／运行任务使用**暂停**，等到已暂停再编辑。**暂停是在安全边界停止，不是立即撤销，也不保证已发出的模型请求免于计费。** 文译在支持的取消／检查点边界停止工作，保留已提交进度。若任务已完成或被新运行替代，请刷新查看状态，不要反复暂停旧任务。

使用**恢复**继续实际被中断的任务，包括准备或 Review，而不是从头翻译整本书。已完成的检查点会复用；中断前未提交的工作可能需要重做。任务失败时，项目总览显示原因，修正后再恢复。导出失败则新建一次导出来重试。

任务排队、运行或正在停止时，项目配置、段落、标题、术语和分析保持只读，仍可阅读、复制。冲突的启动或编辑请求会被拒绝；基于已保存快照的导出可以与翻译并行。其他客户端改动了空闲项目时，应重新进入或刷新读取最新状态，不要把旧页面视为当前状态。

切换页面不会暂停运行。关闭 Web 标签页不停止服务器任务，隐藏 Desktop 不停止本地引擎。Desktop 可同时运行多个项目，没有固定任务数量上限，但共享机器／提供商容量，也可能同时计费；每次运行的模型预算不是账户级共享总额度。暂停和恢复只影响所选项目。

## 人工校阅

打开**人工校阅**对照原文与译文。已解析但未初始化的项目只显示原文；准备完成后会区分待译段落与已保存译文。有意保存的空译文仍算完成。

暂停任务后打开段落，编辑并**保存**。自动刷新不会把未保存的草稿变为正式修订；重新加载、关闭应用或离开需要保留草稿的编辑器前，请保存重要修改。

- **改动记录**用于比较润色与人工修订，也可查看前后全文。载入旧版本只更新编辑草稿，保存后才替换译文。旧项目的“初译 → 当前版本”比较可能包含后续人工或自动修改。
- **精翻初稿**展示三稿项目已归档的 T1／T2／T3 及综合结果。T1 是润色前对照稿，不是选出的赢家。归档综合稿与当前正式译文分开展示，因为后者可能已被人工或 Review 修改。此功能只读，不会重新生成缺失初稿或调用模型。
- **目录与标题**编辑章节译名，保存时也更新关联的 EPUB 目录条目，供后续导出使用；旧导出不变。正文中的标题需在人工校阅中另行编辑。其他人改过同一标题时，请先读取最新值，再保存保留的草稿。

## 管理术语

在**术语表**中维护源词、译词、别名、备注、类型和性别。人物名称使用**人物**筛选统一管理，不另设角色表。日语原文项目还显示读音；仅目标语言为日语不会启用该字段。

搜索覆盖完整术语库，包括别名、读音与备注；类型筛选也作用于结果。全选仅影响当前页，切换页码或筛选会清空选择。任务排队／运行时仍可打开**术语详情**阅读和复制，但新增、导入、编辑、删除及冲突处理均被禁用。

导入支持 **CSV 或 JSON**，CSV 必须有 `source`、`target` 列头。导入检查完整术语库内的同名源词，不限当前页或筛选结果。可导出 CSV/JSON 复用术语；界面类型标签随界面语言变化，内置类型的存储／导出 ID 仍为英文。

### Anki 导出

通过**术语表 → 导出 → Anki 牌组**（`.apkg`）导出完整术语库，不受筛选或选中行影响。它在 `Wenyi` 父牌组下创建项目专属书籍牌组，再按全部术语类型建立子牌组。卡片正面为源词，背面为本书译法、已有读音、备注与别名。

这些是本书采用的译法，不是词典定义。导出不调用模型，不生成读音／例句／音频，不修改词条，也不包含未解决的候选译法。`.apkg` 仅支持导出。

同一项目中源词未变的词条重复导出时保持笔记身份稳定，Anki 可更新内容而不重复建卡或重置复习进度，实际更新取决于其导入设置与修改时间检查。更改源词或换成另一项目会创建新笔记。在文译删除词条不会删除 Anki 卡片；导入不是同步。

## 文风与梗概

在**风格 & 概要**中编辑体裁、语调、叙事、节奏、语域、对话风格、修辞及风格指南。**风格概览 → 保存**一并保存这些风格字段；全书概要有独立保存操作，章节摘要单独编辑。

保存一部分不会丢弃其他部分的草稿。文风／概要草稿按项目隔离，在同一次应用会话中切换页面后保留，但**保存前仅存在于内存**；刷新或关闭应用会丢弃。任务或分析保存请求进行中时，编辑器保持只读。

风格分析提供描述性人物指导，不是另一套人物译名库。模型请求中的名称映射以术语表为准，请在术语表维护。

## 全书 Review

全部章节翻译完成后才能启动**全书审校**。它可以作为已开启的流程步骤运行，也可在审校页面单独启动。结果区分发现的问题、建议和已实际写回章节的修复，历史运行可单独查看。

**`pipeline.review_autofix` 默认 `true`，Review 可以修改正式译文。** 新一轮只需建议、不希望写回时，须在**项目配置**中显式关闭**审校后自动修复并写回正式译文**，保存配置后再启动 Review。英文对应 **Apply autofixes to the saved translation after review**。

关闭 Autofix 只阻止新的发布，**不会**撤销既有修复，也不取消已经开始的写回恢复。如果上次发布在应用修复途中中断，续跑可能先完成这次写回，再检查当前 Autofix 设置。

Review 可复用匹配的已完成结果，或继续中断工作。请检查本次发现与实际发布的修复，不要假定每条建议都已改写书籍。启动前保存人工草稿，接受译文变化后重新导出。

## 导出与删除

### 导出书籍

选择格式，并在支持时选择单语或双语。导出读取**已保存**项目数据的一致快照，可与翻译并行；未保存草稿和快照取得后的修改不会进入该次文件。

普通书籍项目支持 EPUB、DOCX、HTML、TXT 和 Markdown。**PDF 导出仅适用于以 BabelDOC 解析并保存的项目**，经 bridge 保留原始版式。修改当前默认解析器不会把已有 MinerU 项目变成 BabelDOC 项目。参见[格式支持](../reference/formats.md)。

- **Web**：完成后通过浏览器下载。
- **Desktop**：先在系统保存对话框选目标，再开始导出；取消不会创建导出任务或写文件。完成的历史条目也可**另存为…**。覆盖已有文件需确认，传输失败保留原目标。请避开原文和内部项目目录，保存期间不要让其他应用修改同一目标。
- HTML 保存为单个 `.html`，嵌入可读取的本地图片／媒体资源，不使用 ZIP 加资源文件夹；不下载远程 URL。

**每个项目仅保留最近五次完成的书籍导出，长期保存请另存副本。** 编辑后需重新导出，旧文件不会自动更新。术语库有独立的 CSV/JSON/Anki 导出，不占用书籍导出历史。

### 删除项目

**删除项目是永久操作。** 它会移除上传原文、译文、历史、缓存及项目导出文件；确认前先保存需要保留的书籍与术语数据。已经另外保存的下载和其他项目不受影响。

活动任务会阻止删除。删除开始后关闭对话框不能撤回请求。清理失败时，部分文件可能已经移除；应保留项目记录，按错误提示重试，不要假定什么都没变。Desktop 项目文件夹不可用时，移除目录库记录不能擦除断开磁盘上的副本。

## 界面语言

在**设置 → 通用 → 界面语言**选择 **English** 或 **简体中文**。默认英语，不跟随浏览器语言；选择立即生效，刷新后保留，并独立于项目配置。

它只改变界面标签及数字／日期格式，不修改源／目标语言、书籍正文、术语、模型配置或模型生成的分析。切换界面语言不是重新翻译书籍的方式。
