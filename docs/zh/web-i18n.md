# Web 界面语言

[English](../web-i18n.md) · [Web 部署](web.md)

Web 界面默认使用英语，不自动跟随浏览器语言。打开全局 **设置 → 界面语言**，可选择
**English** 或 **简体中文**。界面语言属于浏览器偏好，仅在全局设置中提供。
尚未创建项目时也能访问全局设置，移动端导航同样提供入口，项目任务执行期间仍可切换。

选择立即生效，刷新后保留，并在同一站点的多个标签页之间同步。偏好保存在浏览器的
`wenyi.locale` 中，不写入项目配置。没有已保存语言，或保存了不支持的语言代码时，回退到英语。

界面语言控制导航、表单、通知、内置流程标签、页面标题以及数字和日期格式。它不修改项目的
源语言与目标语言、模型配置、API 标识、原文、译文、术语内容或模型生成的分析。
服务端错误与实时日志按收到的内容展示，完整流程中的未知或自定义标签保留原样。
审校进度摘要翻译已知阶段，阶段未知时使用中性的状态文案。

## 新增语言

前端国际化统一放在 [`apps/web/src/i18n/`](../../apps/web/src/i18n/README.md)：

1. 在 `locales/` 中添加语言文件，以 `locales/en.ts` 为完整消息键基准。
2. 用 `satisfies Messages` 校验词表，保留每条消息的插值参数名。
3. 在 `catalog.ts` 中注册 BCP 47 语言代码、本语言名称及词表。选择器和 `Locale` 类型自动读取注册表。
4. 运行前端类型检查、构建和 Playwright 测试。词表测试会检查所有语言的消息键及插值参数一致性。

带数量或名称的句子使用完整消息，避免拼接翻译片段。原文、译文等项目内容与界面文案分开处理。

## 列表与状态文案

人工校阅使用可搜索的章节行，支持按翻译状态筛选并显示已保存段落数。
全书审校使用可搜索的问题行，可按 **待处理**、**已写回**、**修复失败** 或 **未改变**
筛选。展开后查看证据、建议译文和发布详情，也可跳到人工校阅的对应段落。
翻译完成不代表人工校阅完成。

任务／章节状态文案和徽标颜色统一由 `src/i18n/status.ts` 与 `StatusBadge` 管理。
`done` 和 `completed` 均显示为“已完成”，章节的 `pending` 显示为“待翻译”。
未知代码显示为“未知状态”，原始代码保留在运行原始详情中。此调整只影响展示，不改变 API 或存储状态。

审校处理状态与阶段匹配规则位于 `src/features/review/reviewData.ts`，翻译文案仍统一存放
在语言词表。段落改动记录的标签随界面语言切换，历史文本保持原样。改动记录只记录
文本变化，因此缺少润色记录不代表未执行润色。
