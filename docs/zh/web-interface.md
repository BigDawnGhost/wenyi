# Web 工作流布局

[English](../web-interface.md) · [界面语言](web-i18n.md)

项目导航将 **翻译总览**、**人工校阅**、**全书审校**、**导出**、**术语表**、
**风格与概要**、**项目设置与模型**、**事件日志** 全部平铺，并高亮当前页面。
桌面与手机共用一套导航；字幕项目使用字幕编辑器替代
书籍校阅／审校，不显示术语和风格工具。界面语言仍只在全局设置中调整。
桌面侧栏上方显示项目功能，下方固定放置项目列表、创建项目和设置。
手机端也按项目导航在前、全局入口在后的顺序排列。项目菜单过长时独立滚动，
全局入口不随其滚动。

翻译总览集中提供开始、暂停、续跑、预处理和单章翻译。翻译进度、已记录的累计用时、
总 Token 用量以及匹配当前运行的最新进度始终可见。展开完整流程查看执行计划，
展开用量明细查看 Token 构成、模型／提供商／步骤用量条形图，以及每次运行的耗时图。
项目报告与预处理操作默认折叠。
导出文件的生成及相关选项集中在导出页。

统计区始终显示累计 Token、请求次数、缓存命中率和已记录用时。输入／输出条形图
使用已保存的 Token 数；切换分组不会将不同统计维度重复累加。未记录缓存数据时显示
横线。运行记录按最新在前排列，显示本地化的状态、开始时间和耗时，也可展开更早记录。
计时统计整次运行，包含等待与读写，不计入两次运行之间的暂停，在运行结束或停止时
保存；不会根据 Token 用量推算模型或步骤耗时。窄屏下图表纵向排列。

暂停属于正常操作：项目和任务只显示已暂停，不展示错误提示，事件日志也不记录取消诊断。
已保存的进度可以续跑；预算限制、请求时限和模型失败仍会显示相应的诊断信息。

人工校阅以章节行展示，提供搜索、翻译状态筛选和已保存段落数。进入章节可查看原文
和已保存译文，按需展开润色前译文及审校记录。翻译批次保存后自动刷新；项目任务
运行期间保持只读。

全书审校默认打开最新运行。问题列表可搜索，单条证据、建议修改、发布记录和完整
技术详情按需展开。审校历史默认折叠，选择旧运行后提供返回最新结果的入口。
Autofix 开关始终可见，因为开启后可能更新正式译文。

导出页直接显示格式、单语／双语、生成和下载操作。排版设置折叠时仍显示当前值摘要，
折叠不会重置已填写的选项；导出请求失败时自动展开高级选项。字幕继续使用独立的
编辑与导出流程。

项目设置直接显示模型预设、档位选择和常用流程开关。提供商连接与模型名、分段与性能、
YAML、已保存的操作路由默认折叠并显示摘要。操作覆盖和回退模型仍通过 YAML 编辑，
修改其他字段不会丢失已有覆盖。校验失败后自动展开高级配置，保留无效草稿供修正。
Autofix 开关始终可见，PDF 解析器控件仅在 PDF 项目显示。

标点规范化作为导出高级选项，只影响本次导出请求，不覆盖项目默认值；持久化的导出
默认设置仍可在项目 YAML 中修改。导出按钮会等待默认设置成功加载后启用。

这些改动只整理已有操作的布局，不改变模型提示词、任务状态、审校发布规则或已保存译文。
