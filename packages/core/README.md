# Wenyi Core

Shared translation engine for multilingual long-form documents. It provides
document ingestion, terminology management, contextual translation, polishing,
whole-book review, resumable state, and export services.

For the local command-line application, install **`wenyi-cli`** instead; it
installs this package automatically. Core does not install the Web API or Desktop
application.

PDF layout preservation uses an optional, independently installed
`wenyi-babeldoc-bridge` service over HTTP. BabelDOC is not a dependency of this
package.
