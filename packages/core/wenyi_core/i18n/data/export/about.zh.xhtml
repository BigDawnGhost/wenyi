本书由 文译（Wenyi） 项目生成。

文译是面向书籍与长文本的开源 AI 翻译工具，支持多语言互译，适用于长篇小说、社科专著、纪实文学等内容。项目提供本地桌面应用，同时保留命令行工具和可自部署的 Web 工作台。

文译以全书理解和译文一致性为重点，通过全书预扫、逐章梗概、滚动上下文与实时术语库辅助分批翻译，支持断点续跑、可选润色、取证式全书 AI 审校，以及可视化人工校阅和单语、双语导出，力求在准确的前提下让译文从可读向好读迈进。

项目仍在持续改进，多语言互译仍属实验性功能。译文质量受所选模型、原文和配置影响，可能存在误译、漏译、术语或文风不一致。本页介绍的是项目能力，并不表示本书已启用所有步骤或经过人工校对。
