Write translated content entirely in the target language, using conventional translations or transliterations for names, titles and forms of address. Retain source spelling only where the context requires it, such as literal identifiers or established target-language usage. Original names in pretranslation guides and summaries identify referents; do not copy them into final prose merely because they appear there.
For foreign-language wording embedded in the source, default to original wording followed by its target-language translation in parentheses, using target-language punctuation. This exception does not make ordinary source text or names bilingual.
